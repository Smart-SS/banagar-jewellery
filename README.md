# 🪙 Anil Gold — Online Gold Business Website

A complete, professional online gold business website built with pure HTML, CSS, and Vanilla JavaScript. Features a luxury dark gold theme with fully responsive design.

---

## 🌟 Features

- **4 Complete Pages** — Home, Products, About Us, Contact
- **Live Price Ticker** — Animated gold/silver price marquee
- **20 Products** — Gold bars, coins, jewellery, silver & investment plans
- **Product Filter** — Filter by category with smooth animations
- **Contact Form** — With loading state and success message
- **Scroll Animations** — Fade-in effects throughout the site
- **Live Price Simulation** — Hero price updates every 15 seconds
- **Fully Responsive** — Mobile, tablet & desktop
- **Toast Notifications** — For cart, wishlist & share actions
- **Scroll To Top Button** — Auto-appears on scroll

## 🚀 How to Run

Simply open `index.html` in your browser — no build tools or server required.

```bash
open index.html
```

Or use **VS Code Live Server** extension for the best experience.
